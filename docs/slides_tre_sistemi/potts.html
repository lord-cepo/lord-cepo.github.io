Potts model: order, disorder and Metropolis sampling

96 × 96 sites with periodic boundaries in both directions. The number of sites of each colour can change. One sweep is N proposals.

Each proposal chooses a site and a different state. Matching neighbours lower the energy. Accept the move whenever ΔH ≤ 0 and otherwise with probability exp(−ΔH/kBT).

Heat an ordered configuration through Tc, then cool it. Compare with a random start. Relaxation is slow near the transition. A finite lattice rounds the transition and can retain metastable domains.

H=−J∑⟨i,j⟩δsi,sj

si ∈ {0, …, q − 1}, J > 0. The delta is 1 for equal states and 0 otherwise. Count each bond once.

kBTcJ=1ln(1+q)

Exact value for the ferromagnetic model on an infinite square lattice with no external field.

m=qpmax−1q−1,pa=NaN

m = 1 when all sites share one state, and m approaches 0 when the state fractions are equal. Finite-size fluctuations leave m positive even in the disordered phase.

For q = 2, the Potts model is equivalent to the Ising model with JIsing = J/2, so the critical temperatures agree after converting units. The preceding lattice gas conserves particle number. Potts colours denote discrete states, unlike the geometric orientations of a clock model.
